 STUDENT REGISTRATION FORM

A clean, responsive student registration form built with HTML & CSS & JavaScript.

Live Demo: https://elechigreatness.github.io/STUDENT-REGISTRATON-FORM/

✨ Features
- Student biodata fields (Name, DOB, Gender, Class)
- Parent/Guardian contact section
- Form validation
- Clean UI with school-style layout
- Mobile responsive

 🛠️ Built With
- HTML5
- CSS3
- Form validation

 🚀 How To Use
1. Open `index.html` in browser
2. Fill form and submit
3. To make live: Settings > Pages > Deploy from main
